# Laundry Mart Login Page

## Task
CSS Login Page using Flexbox.

## Files

- index.html
- index.css
- README.md

## How to Run

1. Open `index.html` in a browser.
2. Make sure `index.css` is in the same folder.
3. The CSS file is linked to the HTML file.
4. No Bootstrap or external CSS framework is used.

## Features

- Split-screen login page
- Laundry-themed illustration
- Email input
- Password input
- Forgot Password link
- Login button
- Register Now link
- Flexbox layout
- Responsive design

## CSS Requirement

The main container uses Flexbox:

```css
.login-container {
    display: flex;
